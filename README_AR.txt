Camera Security - Android Port
==============================

هذا مجلد مشروع Android (المصدر)، وليس APK جاهزاً بعد.

المميزات المنقولة:
- كلمة مرور افتراضية: 11227788 (يمكن تغييرها من داخل التطبيق)
- كشف الوجوه باستخدام OpenCV Haar Cascade
- إطار أخضر حول الوجه ووسم Enemy بالأحمر
- وضع الحماية مع تشغيل alarm.mp3 وحفظ لقطة تنبيه
- تصوير يدوي بعد عد تنازلي 3 ثوانٍ
- فلاتر Normal / Gray / Sketch
- معرض داخلي للصور المحفوظة
- About ومعلومات المطور ورابط Instagram
- شعار التطبيق وصوت الإنذار المرفقان

ملاحظات مهمة:
1) الكاميرا تحتاج إذن CAMERA عند أول تشغيل.
2) الصور تحفظ داخل مجلد بيانات التطبيق الخاص (Gallery)، وتظهر أسماؤها في صفحة المعرض.
3) الحماية تعمل أثناء بقاء التطبيق مفتوحاً والكاميرا متصلة؛ لا تدّعي مراقبة الهاتف بالخلفية.
4) اكتشاف الوجه لا يحدد هوية الشخص؛ كلمة Enemy مجرد وسم كما في البرنامج الأصلي.
5) كلمة المرور الافتراضية ظاهرة في التلميح مثل نسخة الحاسوب الأصلية؛ غيّرها بعد أول دخول.

البناء:
- استخدم Ubuntu أو Linux مع Python 3.10+ وBuildozer.
- داخل مجلد المشروع نفّذ:
    git clone https://github.com/Android-for-Python/camerax_provider.git
    buildozer android debug
- أول بناء ينزّل Android SDK/NDK وقد يستغرق وقتاً طويلاً.
- ملف APK الناتج يكون عادةً داخل مجلد bin/.

تنبيه تقني:
Camera4Kivy المستخدم هنا مشروع قديم مؤرشف upstream؛ هذه نسخة مصدر أولية للنقل وتحتاج تجربة بناء فعلية على جهاز Android قبل اعتبارها إصداراً نهائياً. لم يتم بناء APK أو اختباره على هاتف في هذه الجلسة.
